Files

Guest components

Hardware

Can be changed while the VM is stopped.

Display

Applied live while the VM window is open, and saved for next time.

Resolution

Adaptive: the VM takes the size of its window, any shape (portrait too).

Refresh rate

More Hz allows more FPS in games. In quality mode each frame costs CPU time to copy; performance mode avoids that.

Streaming mode

Performance compresses the picture on the VM's GPU (H.264 or HEVC), like Moonlight, so high resolutions and frame rates stay smooth. Quality sends exact, uncompressed pixels.

Codec

More display options (FPS counter, borderless fullscreen with F11, clipboard, audio) are in the VM window: right-click its title bar.

Snapshots

Save and restore the disk; the VM must be stopped.

Settings

For the whole app. Each VM also has its own settings.

Behavior

When closing the window with VMs runningAsk: choose between keeping the VMs running in the tray and shutting them down to exit. Keep running: the window closes and the VMs keep running; open App Sandbox again to bring it back. Exit from the tray icon always asks.

Floating toolbarThe bar that appears when the pointer touches the top edge of a VM window. Its options stay in the title bar menu.

The administrator account in the VM. You sign in with it, and SSH uses it when you turn SSH on.

Options

Manual install: App Sandbox boots the ISO into an empty disk and opens the VM's console; you install the OS yourself. There is no GPU acceleration, shared clipboard, audio or adaptive resolution (those need App Sandbox's guest components). Secure Boot is off. With NAT, set the IP address shown in the VM's Overview by hand; Internal or External networking hands out addresses automatically. When the OS is installed, shut the VM down and choose "Remove installer ISO".

Disk location

Choose an existing folder. Disks are stored in a subfolder named after the VM.
